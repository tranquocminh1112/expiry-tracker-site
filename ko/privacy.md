# 개인정보 처리방침 — Nhắc hạn đồ ăn

_업데이트: 2026년 9월 26일_

> 이 페이지는 참고용으로 제공되는 번역본입니다. **[베트남어 버전](/privacy)이 공식적이고 법적 효력을 가지는 버전입니다.** 내용이 서로 다를 경우 베트남어 원문이 우선합니다.

**Nhắc hạn đồ ăn**("본 앱")은 식품의 유통기한을 기록하고 만료 전에 알려주는 앱입니다. **개발자가 사용자의 데이터를 수집하지 않고 볼 수도 없도록** 설계되었습니다.

## 앱이 저장하는 데이터

- 항목 이름, 수량, 단위, 유통기한, 메모, 사용 기록.
- 사용자가 입력한 이름 또는 별명. 공유 목록에서 추가하거나 사용한 항목 옆에 표시되며, 초대를 보낼 때 이 이름이 초대장에 포함됩니다.
- 알림 설정(알림 시간). 사용자 기기에 저장됩니다.

## 데이터 저장 위치

- 사용자의 iPhone과 **사용자 본인의 iCloud 계정**(Apple CloudKit)에 저장되어 기기 간 동기화됩니다. 개발자는 사용자의 iCloud에 접근할 수 없습니다.
- 항목 이름, 메모, 목록 이름, 추가한 사람의 이름은 사용자 계정에 속한 키로 iCloud 서버에서 **암호화**됩니다.
- **목록을 공유**할 때, 사용자는 각 사람에 대해 **편집 가능** 또는 **보기 전용**을 선택합니다. 상대방은 해당 목록의 모든 내용과 항목을 추가하거나 사용한 사람의 이름을 볼 수 있습니다. 언제든 공유를 중단하거나 사람을 제거할 수 있습니다.

## 앱이 하지 않는 것

- iCloud 외 별도의 계정이나 로그인이 없습니다.
- 광고, 추적(트래킹), 제3자 분석 또는 데이터 수집 도구가 없습니다.
- 어떤 데이터도 판매하거나 제3자와 공유하지 않습니다.

## 오류 신고

**"오류 신고 보내기"**를 누르면 앱과 iOS 버전, 기기 모델, iCloud 및 알림 상태, 목록과 항목의 **개수**, 최근 기술적 오류 코드가 포함된 미리 작성된 이메일이 열립니다. 이메일에는 항목 이름, 메모, 사람 이름이 포함되지 않습니다. 사용자는 내용을 검토하고 수정할 수 있으며, "보내기"를 누르기 전까지는 전송되지 않습니다.

문제가 날짜 형식이나 번역과 관련 있는지 알 수 있도록 지역, 시간대, 앱 언어도 함께 들어갑니다.

## 데이터 내보내기

**설정 → 데이터 내보내기(CSV)** 를 누르면 앱이 기기에서 CSV 파일을 만듭니다. 볼 수 있는 모든 항목의 목록 이름, 품목 이름, 수량, 단위, 유통기한, 메모, **추가한 사람의 이름**, 추가한 날짜가 들어 있습니다. 파일은 보낼 곳이나 저장할 곳을 직접 고를 때만 기기 밖으로 나갑니다. 공유 목록의 파일을 전달하기 전에 한 번 더 확인하세요.

## 알림

알림은 **사용자 기기에서 로컬로** 생성되며 개발자의 서버를 거치지 않습니다.

## 데이터 삭제

**설정 → 모든 데이터 삭제**로 이동하면 기기와 사용자의 iCloud에 있는 모든 목록, 항목, 기록이 삭제됩니다(공유한 목록은 초대받은 사람에게서도 삭제됩니다). 개별 항목이나 목록을 삭제하거나 앱을 삭제할 수도 있습니다. iCloud 데이터는 **설정 → [사용자 이름] → iCloud → 저장 공간 관리**에서 삭제할 수 있습니다.

## 아동

본 앱은 13세 미만 아동을 대상으로 하지 않으며, 고의로 아동의 정보를 수집하지 않습니다.
